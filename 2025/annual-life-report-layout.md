# 年度人生發展成果報告｜動畫效果

> 本文件只描述動畫、互動與演出時序，不包含投影片畫面文字。
>
> 動畫原則：節奏清楚、笑點有停頓、每張只安排 1-3 個主要動態，避免內容被特效蓋過。

## 全局設定

- 投影片比例：固定 16:9，所有內容在同一個舞台內縮放。
- 投影片切換：左右滑入，持續約 400-500 ms。
- 頁面入場：標題先出現，主要內容延遲 150-250 ms 依序淡入並上移。
- 文字動畫：以淡入、上移 12-20 px 為主，不使用彈跳或旋轉文字。
- 數字動畫：重要數字可使用計數器效果；笑點數字保留完整停頓，不要快速跑完。
- 互動按鈕：使用輕微浮動或底線閃動提示可點擊，但不要持續閃爍。
- 動畫速度：一般 300-500 ms；主要視覺登場 800-1200 ms。
- 減少動態：使用者啟用 `prefers-reduced-motion` 時，停用位移、旋轉與大幅度動畫，只保留淡入。

## 1. 封面｜人生目前運作中

### 入場順序

1. 背景與紙張紋理先出現。
2. 小標從左側淡入。
3. 主標逐行淡入，每行間隔 120 ms。
4. 年度副標與姓名從下方上移淡入。
5. 印章或年度標記從透明到可見，微幅旋轉一次後停住。

### 演出節奏

- 主標完全出現後，保留約 1 秒空白。
- 講者走上台、停頓、嘆氣的時間不配合快速動畫，讓現場無奈感成立。

## 2. 年度總結｜人生評分

### 第一階段

1. 標題淡入。
2. 三個分數依序出現：11、6、4 - 1。
3. 每個分數出現後停留約 500 ms，讓觀眾有時間自行誤判。
4. 單位與解釋暫時保持隱藏。

### 第二階段揭曉

1. 講者說出「如果你好奇」後，右側深色資訊區淡入。
2. 「24 小時」由小放大到正常尺寸，持續約 500 ms。
3. 工作、睡眠、休閒娛樂與飯後碳暈依序淡入。
4. `-1` 最後出現，並使用一次短暫的橘色強調。

### 注意

- 不要讓揭曉內容在進入投影片時就先顯示。
- `11` 必須先被觀眾當成分數，再揭露為小時。

## 3. 工作發展｜目前工作

### 入場順序

1. 公司、部門、職稱與年資以資料欄位方式依序淡入。
2. 年資「3 年又 5 天」最後出現，停頓後再由講者解釋聖誕節報到。
3. 條碼槍圖示先出現。
4. 箭頭向右延伸至生產軟體。
5. Error 404 在流程最末端短暫閃現一次，像系統錯誤提示。

### 隱藏按鈕

- 薪資按鈕在頁面進入後保持低調，不主動放大。
- 滑鼠移入時只做輕微上移與邊框變色。
- 點擊後，背景加深，薪資彈窗由下方上移淡入。

## 3A. 薪資彈窗

1. 彈窗背景淡入，主卡片上移 18 px 後停住。
2. 標題先出現。
3. 表格三列依序淡入，每列間隔 100 ms。
4. 價格範圍最後出現，保持模糊感，不做數字計數動畫。
5. 關閉按鈕只做顏色變化，不做誇張旋轉。

## 4. 工作發展｜職涯進度

### 組織圖

1. 原本組織樹從上到下依序建立。
2. 每個節點出現時，連接線延遲 80 ms 再顯示。
3. 右側「對下、對上、對外」三個工作範圍依序從右側滑入。
4. 兩側內容同時停留約 1 秒，讓觀眾看見組織變扁、職責變寬。

### 大龍登場

1. 組織圖停住後，先保留短暫空白。
2. 大龍從畫面右側飛入，持續約 1 秒。
3. 龍身標籤延遲 250 ms 出現。
4. 龍出現後不要再加入其他動態，讓笑點集中在畫面本身。
5. 講者說出「我就是那條龍」後，停頓讓現場反應。

## 5. 感情發展｜在一起，不一定要講道理

### 入場順序

1. 標題先淡入。
2. 「還在一起」以整塊狀態標籤滑入，速度比一般文字稍快。
3. 「細水長流，持續運作中」延遲淡入。
4. 三個經營心法依序出現，每個項目間隔 180 ms。

### 節奏

- 「不講道理」轉場台詞說完後，保留半秒再顯示標題。
- 三個心法不使用卡片彈跳，維持像正式建議的排版，反差會更好笑。
- 免責聲明最後才淡入，速度放慢，讓它像片尾字幕。

## 6. 人生進展｜退休計畫

### 第一階段猜題

1. 進入頁面時只顯示 `1.05^30`。
2. 算式由透明到可見，持續 500 ms。
3. 其他退休資訊保持隱藏。
4. 留出 2-3 秒讓觀眾猜測。

### 第二階段揭曉

1. 每月存款、年報酬率、年限、本金與複利結果依序淡入。
2. 「約 832 萬」使用一次放大強調，持續 500 ms。
3. 三階段卡片從左至右依序出現。
4. 半退休目標顯示後，進度條從 0% 補到 20%。
5. 進度條完成後才顯示配息進度按鈕。

### 配息按鈕

- 按鈕維持固定位置，不因內容入場而跳動。
- 滑鼠移入時輕微上移，點擊後開啟彈窗。

## 6A. 配息彈窗

1. 彈窗背景淡入。
2. 標題先出現。
3. 10 月、11 月、12 月三列依序淡入。
4. 「待確認」保持靜態，不使用假裝更新的動畫。
5. 關閉後回到原本退休頁，不重置整張投影片的進度。

## 7. 年度回顧

1. 標題先出現。
2. 三項成果依序由左側淡入。
3. 右側人生原則區塊延遲 300 ms 後淡入。
4. 「還在工作、還在學習、護照準備好了」可用逐句揭示，但不要超過三段。
5. 這張的動態要比退休頁更安靜，讓內容形成收束感。

## 8. 明年度計畫

### 入場順序

1. 深色背景先出現。
2. `Work is Life` 淡入。
3. 箭頭向右延伸。
4. `Work is Part of Life` 延遲出現並使用螢光色強調。
5. 三個方向依序淡入。
6. 「謝謝大家」最後出現，員購文字延遲 250 ms 出現。

### 結尾節奏

- 結尾文字完全出現後保留 2 秒，不要自動跳頁。
- 讓觀眾有時間反應最後的員購笑點。

## 互動行為

- 左右方向鍵：上一張／下一張。
- 空白鍵：下一張。
- 薪資按鈕：開啟薪資彈窗。
- 配息按鈕：開啟配息進度彈窗。
- `Esc`：關閉目前彈窗。
- 點擊彈窗外部：關閉目前彈窗。

## 不使用的動畫

- 不使用自動播放，避免講者還沒講完就跳頁。
- 不使用持續旋轉、閃爍或彈跳，避免搶走笑點。
- 不讓完整講稿以字幕形式跑過畫面。
- 不讓隱藏資訊提前顯示，尤其是薪資、配息細節與封面內心 OS。
